wasm-ui · two document libraries

This repository is the demo shell for two independent WebAssembly packages. Both run entirely in the browser tab — no server, no upload, nothing installed. Each one lives in its own repository with its own JS/React API; this page just hosts the live demos.

PDF reader → Parse, rasterize and extract text from a PDF.
mountPdfReader(el) · <PdfReader />
DOCX editor → Open, edit and save Word .docx; export PDF.
mountDocEditor(el) · <DocEditor />
